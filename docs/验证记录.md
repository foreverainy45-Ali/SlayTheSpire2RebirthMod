# SeedRestart 0.5.2 正式版与 public-beta 验证记录

日期：2026-11-19。环境：Windows、正式版 v0.107.1（59260271）与 public-beta v0.113.1（d09d48e5）。

## 验证方式

使用项目内独立游戏副本，以及 Single、Host、Client、Client2、Client3 五个 SeedRestart 专用用户目录。正式游戏存档、已安装 Mod 文件和配置未被覆盖。组合为 JmcModLib 1.10.0、QuickSL 1.9.0、BetterSaveSlots 1.2.2 与 SeedRestart 测试构建。

测试驱动只编译进隔离测试 DLL；正式发布 DLL 不包含驱动。界面测试检查 JmcModLib 按钮注册，并驱动游戏原生 `NGenericPopup` 的确认/拒绝信号。联机测试使用本机 ENet 的独立游戏进程，实际传输投票、准备、提交、加载屏障与 QuickSL 消息。

## 0.2.1 修复与回归

0.2.0 的按钮已注册，但在 public-beta 中 Mod 初始化发生在 `NGame._Ready` 之后，旧实现错过控制器创建时机，点击后因控制器为空而静默返回。0.2.1 在初始化时挂接现有 `NGame`，点击时再次兜底检查，并在无法执行时显示游戏原生提示框；QuickSL 晚于本 Mod 加载时也会重新挂接只读状态与入口保护。

| 项目 | 结果 |
| --- | --- |
| 单人实际按钮回调 | 5 轮取消/确认通过；确认框正常出现，确认后同角色、新种子回到涅奥并写入失败，耗时 3293–3590 ms |
| 单人 QuickSL 回归 | 5 轮“换种重开后立即 QuickSL”通过 |
| 双人实际按钮回调 | 客户端、房主各发起 1 轮；拒绝无副作用，同意后双方各写 1 条失败，连接与角色保持，耗时 3659–3845 ms |
| 双人 QuickSL 回归 | 3 轮交替发起换种并立即 QuickSL 均通过，耗时 3450–3915 ms |
| 初始化顺序 | 两端均记录控制器挂接；QuickSL 晚加载兼容层识别为 1.9.0、`supported=True` |

## 当前边界

- 自动测试验证入口注册、原生弹窗信号、失败结算和真实游戏进程内重开；正常窗口下的最终鼠标位置、字体与视觉仍需人工验收。
- 本机 ENet 通过不等于 Steam 公网、跨机器、异常丢包、提交期间断线或房主崩溃已经验证。
- 支持 Standard、Daily 与 Blitz；Dread、第三方角色和复杂内容 Mod 未纳入本轮验证。
- 无头引擎可能输出原生空纹理告警；上述用例均以最终状态、进度、历史文件和连接身份共同判定。
