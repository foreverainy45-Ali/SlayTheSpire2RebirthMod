# SeedRestart v0.5 正式版兼容需求文档

文档状态：已完成 Standard 单人实机验收
目标版本：v0.5.0
适配基线：正式版 v0.107.1、public-beta v0.113.1、JmcModLib 1.10.0
日期：2026-11-16

## 1. 目标

在不改变 v0.4.1 public-beta 已验证流程的前提下，使同一发布 DLL 能在正式版 v0.107.1 初始化和运行。正式版兼容属于独立适配层，不能用降级 beta 功能或维护两个互斥发布包实现。

## 2. 版本能力差异

- 正式版大厅玩家类型为 `LobbyPlayer`，beta 为 `StartRunLobbyPlayer`。
- 正式版 `INetGameService` 没有 beta 的 `LocalVersion` 属性。
- 两版 `StartRunLobby` 构造函数及监听接口签名不同。
- 正式版 `RunState.CreateForNewRun`、`Rng`、确定性哈希及 `NGame.StartNewSingleplayerRun` 签名较旧。
- 正式版没有 Blitz、Dread、`RunState.IsCustomGame`、`RunManager.IsChangingRooms` 和 `MerchantSynchronizer`。
- 正式版单人新局需要沿用原生入口完成全局解锁状态、共享远古事件及房间池初始化。

## 3. 兼容原则

1. beta 原有单人及多人重开主流程不变。
2. 仅通过版本能力检测进入正式版专用逻辑，不用宽泛异常吞噬掩盖版本差异。
3. 跨版本类型差异集中在 `GameCompatibility` 与动态代理中，业务协议和失败结算不复制两套。
4. 正式版 Standard 单人调用原生 `StartNewSingleplayerRun`，MOD 继续负责失败结算、种子选择、恢复文件及涅奥标记。
5. 正式版没有 Blitz 时不显示或伪造该模式；beta 继续支持 Blitz。
6. 未识别的游戏版本继续在安装补丁前安全停用。

## 4. 当前验收范围

- 已通过：正式版 Standard 单人按钮、确认框、失败历史、新种子、角色保留、回到涅奥、连续重开和原生等待框。
- 编译通过：正式版 v0.107.1 与 public-beta v0.113.1，均为 0 错误、0 警告。
- 继承验证：beta v0.113.1 的 Standard、Daily、Blitz、2–4 人联机和 QuickSL 回归记录。
- 待实机验证：正式版 Daily、正式版多人、Steam 公网和异常断线恢复。
